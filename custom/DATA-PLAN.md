## Tested sources
No external API, feed, or connector is used. Catalog and orders are owned by this artifact's own database. Product data is sample data explicitly requested by the user in this build request, seeded once via a post-submit action and clearly usable as demo inventory until replaced with real stock.

### Sample catalog (user-authorized invented data)
**Used by**: `listProducts`, `getProduct`, `seedSampleCatalog`
**Content**: 12 red model cars — 4 per scale (1:64, 1:32, 1:16). Fields per row: name (real car model names in red), brand, scale, shade of red, price VND, promo price, stock, description, features (opening parts by scale: 1:16/1:32 openable, 1:64 sealed), image key.
**Processing**: Seeded once if products table is empty; never overwritten on read/refresh. Prices are demo prices in VND formatted vi-VN. All rows are sample rows per explicit user request.
